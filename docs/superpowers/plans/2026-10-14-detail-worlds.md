# Per-Project Detail Worlds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each `/projects/[slug]` detail hero renders its own baked Blender diorama behind the title, reusing the intro forest pipeline.

**Architecture:** One parameterized headless-Blender builder (`art/build_detail.py --slug`) bakes vertex-color Draco GLBs; a new `DetailWorlds` R3F chapter mounted only in `mode==="detail"` loads the current slug's GLB with the existing baked material and fades the shared smoky backdrop out.

**Tech Stack:** Blender 4.x headless `bpy`, Cycles vertex bake, glTF-Draco, Next.js 16, react-three-fiber 9, three 0.186, zustand `useApp`, GSAP (fade only).

**Spec:** `docs/superpowers/specs/2026-10-14-detail-worlds-design.md`

## Global Constraints

- Blender binary is `/Applications/Blender.app/Contents/MacOS/Blender`, run with `-b --factory-startup -P`.
- Output path is exactly `public/models/detail-<slug>.glb` for slugs in `src/content/site.ts`: `school-system, legal-workspace, luxe, goldos, vyro, healthhub`.
- Budget per GLB: <100k verts pre-decimate, <1.5 MB on disk, vertex colors only (no image textures), `export_draco_mesh_compression_enable=True`.
- Runtime must respect `lite===true` (do not mount), `quality==="low"` / `isMobile` (no volumetrics, halved particles), `prefers-reduced-motion` (no drift).
- Detail camera fixed at approx `[0, 1.6, 7]` look `[0, 1.2, 0]` + pointer parallax only; do not alter journey `CameraRig` keys.
- Keep `ProjectDetail.tsx` DOM unchanged except opacity hooks if needed; cover `<Image priority>` stays as LCP fallback.

## Review Focus

- Direct URL load on `/projects/school-system` shows cover first, then 3D fades in with no white flash — test by disabling cache and measuring first paint.
- Fast slug-to-slug navigation (`luxe` → `goldos`) never shows previous slug's world and never leaks GPU memory — test by switching 5 times and checking `renderer.info.memory.geometries` stable.
- Mobile + `lite` path renders readable hero with zero WebGL contexts — test with `?lite` / small viewport and confirm no canvas mount.
- Long titles (`Legal Workspace`) stay legible over bright tint areas — test with luminance screenshot check on each world.
- Missing/corrupt GLB falls back to cover + `DetailBackdrop` without crashing the canvas — test by renaming one GLB and loading that slug.

## File structure

- `art/build_detail.py` (CREATE): parameterized builder, `--slug <slug> [--render]`; per-slug config dict (silhouette, palette, seed); EEVEE preview + Cycles `COMBINED` bake to `Bake` vertex colors with `BAKE_SCALE=4.0`; saves `art/detail-<slug>.blend` for inspection.
- `public/models/detail-<slug>.glb` (GENERATED by above, pilot: `detail-school-system.glb` in Task 1, rest in Task 3).
- `src/experience/chapters/DetailWorlds.tsx` (CREATE): owns slug → URL map, `useGLTF` load, baked material via `makeBakedMaterial` from `./Forest`, tint point light from `getProject(slug).tint`, drift + fade, sets `detailReady` flag.
- `src/experience/Experience.tsx` (MODIFY): mount `<DetailWorlds />` + `<DetailBackdrop />` outside journey group; journey group stays `visible={mode==="journey"}`.
- `src/experience/chapters/DetailBackdrop.tsx` (MODIFY): subscribe to `detailReady`, tween `uOpacity` to 0 and unmount-safe skip of `useFrame` when done.
- `src/store/useApp.ts` (MODIFY): add `detailReady: boolean` + setter via existing `set`.
- `src/lib/sceneState.ts` (READ-ONLY): confirm `dive/intro` are journey-only, do not reuse for detail fade.
